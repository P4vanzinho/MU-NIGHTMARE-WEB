# MU Nightmare Web

Portal web do MU Nightmare, construído do zero em TypeScript.

O diretório `mu-nightmare` ao lado deste repositório é apenas a referência visual do protótipo. Esta aplicação terá implementação, contratos, banco e integrações próprios.

## Desenvolvimento

O trabalho ativo acontece na branch `development`. As branches `staging` e `main` recebem apenas mudanças validadas conforme o fluxo definido no plano.

## Direção técnica

- React + TanStack Start
- Better Auth
- PostgreSQL + Drizzle
- Tailwind + shadcn/ui
- OpenMU simulado localmente antes da integração real

Consulte [`plans/plano-implementacao-mu-nightmare.md`](plans/plano-implementacao-mu-nightmare.md) para as fases e critérios de aceite.
